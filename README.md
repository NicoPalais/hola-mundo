# Hola mundo

Una página estática de «¡Hola, mundo!» creada por Nico. No necesita instalación ni compilación: abre `index.html` en un navegador para verla.

## Publicar en GitHub Pages

1. Sube los archivos a la rama que quieras publicar (por ejemplo, `main`).
2. En el repositorio de GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, elige la rama y la carpeta **/(root)** y guarda.
4. GitHub mostrará la dirección de la página cuando termine el despliegue.

Las pestañas muestran ejemplos de código; el botón Ejecutar muestra un resultado de ejemplo, sin ejecutar código arbitrario.
